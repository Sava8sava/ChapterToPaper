"o aplicativo deve ser capaz de receber o link da novel, nessa primeira versão especificamente o link que já esta em um cap, ele deve receber uma quantidade de cap desejados, ele deve conseguir baixar a quantidade de cap desejada partindo do cap que foi passado pelo link, ele deve converter para ebup(para leitura pelo kindle) depois juntar esse capitlos num só ebup e salvar localmente" 

RF:
1. Deve ser capaz de enviar requisições para sites a partir do link 
2. dev ser capaz de encontrar o link do proximo cap 
3. deve ser capaz de converter para ebup e compilar os capitulos 
4. deve ser capaz de salvar localmente

RNF:
1. deve ser capaz de passar pelo captcha,uso de user-agent 
2. deve ser capaz de identicar o eloemento html do proximo cap 


#ideias 
- usar request + bs4 para as paginas por enquanto(possivel troca para Selenium, talvez o uso de SOLID para criar modulos desacoplado).
- Usar Ebooklib para a conversão em ebup ou calibre para funcionar com certeza no kindle.
- usar fake-user agent para RNF1
- para a RNF2, a ideia é o usuario entra com um arquivo json que identifica qual é o html do proximo cap 
- usar uma pausa de tempo entre bauxar capitlos consideravel para evitar muitas requisições 

Fluxo: salva o HTML da pagina->identifica o proximo cap e repete o processo->ao baixar todos converte para ebub-> junta em um só ebub->limpa o que sobrou->salva o epub final.
